# golib

`golib` is a collection of Go packages designed to simplify the development of Go applications, particularly microservices. It provides a set of utilities for common tasks such as making HTTP requests, interacting with databases, and connecting to the Ethereum blockchain.

## Packages

`golib` includes the following packages:

*   **cache**: Caching utilities.
*   **config**: Application configuration management.
*   **context**: Context management.
*   **custerr**: Custom error handling.
*   **database**: Database utilities for SQL and NoSQL databases.
*   **ethereum**: An Ethereum client for interacting with the Ethereum blockchain.
*   **event**: Event handling.
*   **fileutils**: File utilities.
*   **grpc**: gRPC client and server utilities.
*   **http**: A generic HTTP client.
*   **log**: Logging utilities.
*   **response**: Standardized response formats.
*   **router**: HTTP router.
*   **tracing**: Distributed tracing.
*   **txmanager**: Transaction management.
*   **utils**: General-purpose utilities.

## Getting Started

To use `golib` in your project, you can install it with `go get`:

```bash
go get github.com/nocturna-ta/golib
```
